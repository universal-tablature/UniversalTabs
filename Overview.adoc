= Overview (Non-Normative)

== Use Cases

The use cases are:

* Music teaching apps (e.g. Yousician, Simply Piano, Flowkey, Rocksmith, Slopsmith etc.)

* Tabulature rendering apps (e.g. Guitar Pro, TuxGuitar, MuseScore etc.)

* Music notation apps (e.g. Finale, Sibelius, Dorico etc.)

* Music composition apps (e.g. Ableton Live, Logic Pro, Cubase etc.)

* Music performance apps (e.g. GarageBand, BandLab, Soundtrap etc.)

* Historical music research, e.g. capturing how performance is done on a particular instrument, or how a particular instrument is played in a particular style.

* Robotic performance of instruments, e.g. for museums.

* AI-assisted composition and arrangement tools that preserve editable musical
  structure instead of only producing audio samples.

* Playability-aware generation and repair, i.e. no music requiring 11 fingers
  to play, 3 hands, 2 mouths, or impossible actuator transitions.

* Musical IDE workflows where sections, chord annotations, instrument
  realizations, tablature, MIDI, and MusicXML exports can be edited and
  regenerated independently.

See xref:Tools/Overview.adoc[tooling requirements] for non-format software
requirements.
